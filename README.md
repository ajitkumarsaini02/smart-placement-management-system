# PlaceTrack — Smart Placement Management & Tracking Platform

A premium, modern, fully responsive **LIGHT-THEME ONLY** SaaS landing page built for college placement cells, students, and corporate recruiters.


---

## 🌟 Key Features & Sections

1. **Sticky Glassmorphic Navigation Bar**
   - Brand logo with graduation cap emblem (`PlaceTrack`).
   - Smooth anchor navigation: Home, Features, How It Works, About, Top Recruiters, Contact.
   - Live cycle badge (`Drive 2026 Active`) and `Get Started` CTA.
   - Fully responsive slide-down mobile navigation menu with backdrop blur.

2. **Hero Section with Interactive Dashboard Preview**
   - Headline: *"Your Career Journey Starts With the Right Opportunity."*
   - Description: *"Discover placement opportunities, track applications, connect with top recruiters, and take control of your professional future with PlaceTrack."*
   - Dual Call-to-Actions: `Explore Opportunities` and `Learn More`.
   - Visual SaaS Dashboard Preview on the right featuring:
     - **Placement Statistics**: 14 Active Drives, 5 Shortlisted, 44.5 LPA Top Offer, 2 Interviews Today.
     - **Recent Job Opportunities**: Google, Microsoft, Amazon with CTC, eligibility criteria, and deadlines.
     - **Application Pipeline Progress**: Visual multi-step tracker (Applied → Shortlisted → Tech Round → Offer Letter).
     - **Upcoming Interviews**: Atlassian System Design, Adobe HR, Goldman Sachs Assessment.

3. **Statistics Section (Illustrative/Demo Metrics)**
   - **5,000+** Registered Students
   - **150+** Partner Companies
   - **1,200+** Successful Placements
   - **95%** Placement Assistance
   - Labeled clearly with scope badges and trend indicators.

4. **Features Section (6 Premium Cards)**
   1. **Smart Job Discovery**: Precision matching by CGPA, branch, and package brackets.
   2. **Resume Management**: TPO-verified ATS resume versions.
   3. **Eligibility Checker**: Real-time evaluation against backlog and GPA rules.
   4. **Application Tracking**: Live pipeline with timestamped stage changes.
   5. **Interview Scheduling**: Frictionless slot bookings with conflict prevention.
   6. **Placement Analytics**: Cohort benchmarks, branch-wise statistics, and salary percentiles.

5. **How It Works (Connected 4-Step Process)**
   - Step 1: Create Your Profile
   - Step 2: Explore Opportunities
   - Step 3: Apply for Jobs
   - Step 4: Track Your Success
   - Interactive deep-dive viewer with live mock data simulations.

6. **Top Recruiters Section**
   - Verified brand cards: **Google, Microsoft, Amazon, Infosys, TCS, Accenture, Goldman Sachs, Adobe**.
   - Filterable categories: *Super Dream*, *Core IT*, *Consulting & Tech*, *Fintech Dream*.

7. **Why Choose PlaceTrack (Modern Split Comparison)**
   - Centralized placement information
   - Easy application tracking
   - Transparent recruitment process
   - Better student opportunities
   - Interactive toggle comparing PlaceTrack against chaotic traditional spreadsheet/WhatsApp systems.

8. **Student Testimonials**
   - Real student reviews placed at Google (43.5 LPA), Amazon (38.2 LPA), and Microsoft (44.0 LPA).

9. **FAQ Section (Expandable Accordion)**
   - Smooth accordion interactions for all 5 core questions.

10. **Final Call-to-Action (CTA)**
    - Headline: *"Your Dream Career Is Just One Opportunity Away."*
    - Description: *"Stay prepared, discover opportunities, and make your next career move with confidence."*
    - Quick demo access and TPO contact channels.

11. **Institutional Footer**
    - Platform mission, verified contact channels (email, phone, TPO room location), quick links, features, and social profiles.

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
